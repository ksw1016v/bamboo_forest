# 대숲툰 소재 목록

오픈채팅과 사연에서 나온 주제를 각색한 소재. 쓴 소재는 `[x]`와 화수를 표시한다.
목록이 바닥나면 설계사의 일상·영업 현장 공감 주제로 새로 만들어 아래에 추가한다 (콘텐츠 기준은 TOON_GUIDE.md).

## 사용함
- [x] 환영이 환수로 보이는 월말 (1화)
- [x] 이관 DB가 전부 전임자 지인 (2화)
- [x] SNS 속 최연소 지점장·전국 1등 (3화)
- [x] 정보를 다 줬더니 읽씹 (4화)
- [x] 지인영업 꼭 해야 하나요 (5화)
- [x] 상담 중 계속 울리는 전화 (6화)
- [x] 갈까 말까 할 땐 가라 (7화)

## 남은 소재
- [ ] 연락이 끊겼더니 회사에 '그만뒀다'고 소문이 난 날 (복귀하는 발걸음)
- [ ] 코드 나오기 전날 밤 "내일부터 일하라니 무서워요"
- [ ] 누구는 고객 수백 명, 나는 10명도 안 될 때
- [ ] 올해 처음 시작했는데 11~12월은 어떤 달이에요? (연말 분위기)
- [ ] 신인이 그만둬도 아무도 안 잡는 지점에서 혼자 버티기
- [ ] 사람을 만나야 일이 시작되는데 만날 사람이 없을 때
- [ ] AI가 못 하는 건 공감 (정보는 AI, 마음은 설계사)
- [ ] 스레드·인스타 일주일 키워본 설계사의 SNS 도전기
- [ ] 명절 고객 관리, 선물 대신 할 수 있는 것
- [ ] 대리점 옮기기 전 마음 정리 (특정 규정·회사 없이 마음가짐만)
- [ ] 좋은 관리자란? 출근 잘하고 관리 잘하는 사람은 제도와 상관없다
- [ ] 단톡방 실적 인증이 무서워요
- [ ] 거절 9번 당한 날, 10번째 전화를 못 걸겠을 때
- [ ] 가족이 "그 일 언제까지 할 거야?"라고 물을 때
- [ ] 미팅 노쇼 당하고 카페에 혼자 남은 날
- [ ] 월말 마감 D-3, 숫자가 안 보일 때
- [ ] 동창회에서 다들 나를 피하는 것 같은데 오히려 내가 영업당함
- [ ] 소개팅에서 직업 말하자마자 "저 보험 다 있어요"
- [ ] 엄마가 친구들한테 내 명함을 돌렸는데 다들 자식이 설계사
- [ ] 단골 카페 테이블마다 설계사와 고객
- [ ] "다음 주에 연락 줄게요"가 7번째 다음 주
- [ ] 차가 제2의 사무실 (트렁크엔 볼펜 20자루)
- [ ] 주말에 폰이 울리면 심장이 먼저 뛴다
- [ ] 대나무숲 오프라인 모임 첫 참석기 ("이름도 안 물어봐요")
- [ ] 바람 불면 '임금님 귀는 당나귀 귀' 소리가 나는 곳 (대나무숲 이름 이야기)
