# bf-dm — DM 문구

대나무숲 DM은 대부분 **사연**이다. 영업 DM이 아니라 "들어 주는 사람"의 답장을 쓴다. 모르는 사람에게 먼저 보내는 DM은 쓰지 않는다.

## 1. 사연 받았을 때 첫 답장
- 첫 문장에서 사연의 구체적인 장면 하나를 짚어 준다 (읽었다는 증거)
- 위로 한 줄, 판단·충고는 하지 않는다
- 소개 여부는 **반드시 동의를 묻는다**
```
보내 주셔서 고마워요 🐼 마감 전날 철회 연락 받으신 장면, 읽는 저도 철렁했어요.
그날 버틴 것만으로도 충분히 잘하신 거예요.
혹시 이 이야기를 이름·회사 지우고 대숲툰 소재로 써도 될까요? 싫으시면 편하게 말씀해 주세요!
```

## 2. 동의를 받았을 때
- 각색 방식(이름·회사·지역 삭제, 상황 바꿈)을 한 줄로 설명하고, 게시되면 알려 드린다고 약속
- 동의 없이 소재로 쓰지 않는다. 원문 인용·닉네임 금지 (TOON_GUIDE)

## 3. 오픈채팅·모임 안내
- 상대가 먼저 관심을 보였을 때만. "프로필 링크에 오픈채팅이 있어요" 한 줄로.

## 4. 후속 메시지 (최대 1개)
- 답이 없으면 3~4일 뒤 한 번만: "그날 이후로 조금은 괜찮아지셨어요? 🎋"
- 인스타 규칙상 상대가 마지막으로 보낸 지 24시간이 지나면 보낼 수 없다는 점을 알려 준다.

## 하지 말 것
- 보험상품·보험료·보험금·보험사명 언급, 가입·리크루팅 권유
- 심리 상담처럼 진단하기. 힘든 정도가 심해 보이면 주변 사람이나 전문 상담을 권한다.

메시지마다 `[언제 보내는지]` 를 붙이고, 3~5문장 이내로.
