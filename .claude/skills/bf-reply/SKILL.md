# bf-reply — 댓글 답글

대나무숲 댓글은 **공감받으러 온 사람**이 대부분이다. 빨리, 한 명 한 명 이름 불러 주듯 답할수록 숲이 커진다.

## 1단계: 분류하고 개수 말하기
| 분류 | 어떤 댓글 | 답글 |
|---|---|---|
| **털어놓기** | 자기 힘든 경험 | 가장 정성껏. 그 장면을 받아 주고, 작은 위로 한 줄. 필요하면 "DM으로 더 들려주세요 💌" |
| **공감** | "저도요ㅠㅠ", "완전 제 얘기" | 짧게 맞장구 + 한 마디 응원 |
| **질문** | 노하우·방법 질문 | 짧게 답하고 **다음 대숲툰 소재 후보로 적어 둔다** (`toon/TOPICS.md`) |
| **경험 공유** | 자기 팁 | 고맙다고 하고 핵심을 다시 짚어 주기 |
| **응원** | 🔥, 친구 태그 | 3~8자 ("함께해요 🐼") |
| **스팸·악의** | 리크루팅 광고, 비하 | 답하지 않음. 숨기기 권장 |

## 2단계: 답글 쓰기
- 계정 존댓말에 밤부 따뜻함. 이모지 0~1개 (🎋 🐼 💚)
- **절대 금지**: 보험상품·보험료·보험금·보험사명 언급, 가입 권유, 리크루팅 권유, 실적 압박, 고객 탓
- 상품·약관·청구 질문이 오면 "그건 회사 교육팀이나 지점장님께 꼭 확인해 보세요!" 수준으로만
- 같은 문장 반복 금지 (스팸 판정 방지)

## 출력
```
댓글 24개 · 털어놓기 3, 공감 12, 질문 2, 경험 공유 2, 응원 4, 스팸 1

[털어놓기] @abc: 오늘 철회 문자 받고 차에서 울었어요
→ 그 문자 받는 순간 얼마나 철렁했을지 알아요 💚 오늘은 차에서 운 것까지가 할 일이었어요. 내일 숲에서 다시 만나요.
...
다음 화 소재 후보: 첫 상담 때 무슨 말부터 해요?
```
